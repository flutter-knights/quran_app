# Settings Page & 4-Palette Theme System — Design Spec

**Date:** 2026-05-24  
**Status:** Approved

---

## Overview

Replace the settings bottom sheet with a full settings page, and replace the single dark/light color palette with a 4-palette theme system. The user picks one of four palettes from a dedicated 2×2 swatch widget on the settings page; the selected palette drives the entire app theme.

---

## Decisions

| Question | Decision |
|---|---|
| Settings surface | Full page (push navigation via GoRouter) |
| Theme model | Single 4-way palette picker; `isDarkMode` field removed |
| Palette widget style | 2×2 color swatch grid |
| Settings page structure | Sectioned: APPEARANCE / GENERAL / NOTIFICATIONS |
| Mushaf-specific colors | Getters on `ColorPalette` extension (no ThemeExtension needed) |

## Section 1: Color & Theme Layer

### `lib/core/constants/color_palette.dart` *(new)*

Pure-Dart enum, no Flutter imports, safe for domain layer.

```dart
enum ColorPalette { neutralDark, neutralLight, slateDark, slateLight }
```

### `lib/config/theme/app_palette.dart` *(new)*

Extension on `ColorPalette` that produces Flutter types. All color values sourced from `app_redesign.html`.

**Getters per palette:**

| Getter | neutralDark | neutralLight | slateDark | slateLight |
|---|---|---|---|---|
| `bg` | #0D0D0D | #F4F4F4 | #0A0C10 | #F0F3F8 |
| `surface` | #1A1A1A | #EAEAEA | #141820 | #E2E8F2 |
| `primary` | #2E5244 | #2E5244 | #1C4558 | #1C4558 |
| `secondary` | #5C8070 | #5C8070 | #4878A0 | #4878A0 |
| `onSurface` | #F5F5F5 | #141414 | #F0F4F8 | #0A0C12 |
| `onSurfaceVar` | #8A8A8A | #686868 | #8A92A0 | #5E6880 |
| `mushafBg` | #1C1A14 | #FFFCF5 | #111620 | #F8FBFF |
| `mushafText` | #D4C5B0 | #1A1208 | #C8D4E0 | #0A0E14 |

`isDark` → true for `neutralDark` / `slateDark`.

`mushafBorderColor` → `rgba(255,255,255,0.06)` for dark palettes, `rgba(0,0,0,0.06)` for light palettes.

`colorScheme` getter → builds a `ColorScheme` from the above colors. Error color is `Color(0xFFE67E7E)` (unchanged across all palettes).

`toThemeData()` → returns a `ThemeData(useMaterial3: true, colorScheme: colorScheme, inputDecorationTheme: ...)` matching the structure of the current `dark_theme.dart`.

### `lib/config/theme/app_colors.dart` *(modified)*

Stripped to a single constant:
```dart
static const Color error = Color(0xFFE67E7E);
```
All old palette constants (onyx, evergreen, pineTeal, deepTeal, greyOlive, brightSnow, lightMist, lightCoral) removed.

### `lib/config/theme/color_scheme.dart` *(modified)*

The two `ColorScheme` constants (`darkColorScheme`, `lightColorScheme`) are removed — now generated by `AppPalette.colorScheme`. The `ColorSchemeExtension` on `BuildContext` stays unchanged.

### `lib/config/theme/dark_theme.dart` and `light_theme.dart` *(deleted)*

Replaced by `ColorPalette.toThemeData()`.

### `MaterialApp` wiring

The app root wraps `MaterialApp` in a `BlocBuilder<SettingsCubit, SettingsState>`:
```dart
BlocBuilder<SettingsCubit, SettingsState>(
  builder: (context, state) => MaterialApp.router(
    theme: state.settingsModel.palette.toThemeData(),
    // no darkTheme / themeMode needed
    ...
  ),
)
```

## Section 2: Settings Entity & Cubit

### `lib/features/settings/domain/entities/settings.dart` *(modified)*

- Remove field: `final bool isDarkMode`
- Add field: `final ColorPalette palette` (default: `ColorPalette.neutralDark`)
- Update `copyWith` and `props`

### `lib/features/settings/data/models/settings_model.dart` *(modified)*

- `fromMap`: parse `map['palette']` → `ColorPalette.values.firstWhere((p) => p.name == map['palette'], orElse: () => ColorPalette.neutralDark)`. Remove `isDarkMode` key.
- `toMap`: write `'palette': palette.name`. Remove `'isDarkMode'` key.
- `copyWith`: add `ColorPalette? palette` parameter.

**Migration:** HydratedBloc restores from persisted JSON. On first launch after update, the missing `palette` key defaults to `ColorPalette.neutralDark`; the stale `isDarkMode` key is silently ignored. No explicit migration step required.

### `lib/features/settings/presentation/cubit/settings_cubit.dart` *(modified)*

- Remove `isDarkMode` parameter from `updateSettings()`
- Add method:
  ```dart
  void updatePalette(ColorPalette palette) {
    emit(SettingsState(state.settingsModel.copyWith(palette: palette)));
  }
  ```
- Initial default state uses `palette: ColorPalette.neutralDark`

## Section 3: Settings Page, Palette Widget & Navigation

### `lib/config/router/app_router.dart` *(modified)*

- Add `static const String settingsPath = "/settings"`
- Add `GoRoute(path: settingsPath, pageBuilder: GoTransitions.fade.withFade.build(builder: (_, __) => const SettingsPage()))`

### `lib/features/settings/presentation/pages/settings_page.dart` *(new)*

`Scaffold` with:
- `AppBar`: back button (auto), title "الإعدادات", styled to match the app bar design
- `body`: single `ListView` with padding, containing 3 labelled sections:

  **APPEARANCE**
  - `PalettePickerWidget`

  **GENERAL**
  - `SettingSwitch` for 12-hour format (`isFormat12Hours`)
  - `SettingSwitch` for Arabic language (`isArabic`)

  **NOTIFICATIONS** *(shown only if `FeatureFlags.pinnedPrayerStripUi`)*
  - `ListTile` → navigates to `AppRouter.notificationsPath`

Section labels match the app's existing `section-label` pattern: small, uppercase, `onSurfaceVariant` color.

Uses `BlocBuilder<SettingsCubit, SettingsState>` to read current settings. Writes via `sl<SettingsCubit>()`.

### `lib/features/settings/presentation/pages/widgets/palette_picker_widget.dart` *(new)*

A `StatelessWidget` that renders the 2×2 palette swatch grid.

Props: `currentPalette: ColorPalette`, `onSelect: ValueChanged<ColorPalette>`.

The `SettingsPage` passes `onSelect: (p) => sl<SettingsCubit>().updatePalette(p)` — the widget itself has no DI dependency.

Each tile:
- `Container` with `decoration: BoxDecoration(color: palette.bg, borderRadius: ..., border: selected ? Border.all(color: palette.secondary, width: 2) : ...)`
- Inside: palette name text (in `palette.onSurface` color) + thin `primary`-colored bar at bottom
- Selected tile shows a small checkmark icon in `palette.secondary` color at top-right
- `onTap` → calls `onSelect(palette)`
